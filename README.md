# Wrkman Installer Support Portal

A responsive React + Vite starter project for an installer help and training portal.

## Requirements
- Node.js 20.19+ or 22.12+ recommended
- npm
- Visual Studio Code (recommended)

## Run locally
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address printed in the terminal (usually http://localhost:5173).

## Create a production build
Run `npm run build`. Vite creates the deployable website in the `dist` folder.

## Main files
- `src/App.jsx`: page layout and interactive components.
- `src/data.js`: editable troubleshooting topics, training modules and 30 assessment questions.
- `src/styles.css`: responsive design and branding styles.
- `index.html`: page title and metadata.

## Important content notes
This is a functional starter template. Replace sample troubleshooting steps with Wrkman-approved procedures before publishing. Video items are placeholders until you add approved training video URLs. The assessment questions are sample knowledge-check questions and should be reviewed by the relevant technical team before being used for formal installer certification.

## Branding
The project uses a clean green Wrkman-inspired palette and a text-based logo placeholder. Replace it with the official Wrkman logo and brand colours if you have approved brand assets.
